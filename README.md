# Chapter Creator

A local Windows desktop app for creating chapter folder structures automatically.

## Features

- Create chapter folders automatically
- Supports existing works and new works
- Creates three subfolders:
  - الفصل
  - التحرير
  - التسليم
- Structure preview
- Recent activity
- Light/Dark mode
- First-launch workspace folder setup
- Fully local/offline

## Installation

```bash
pip install -r requirements.txt
```
